# Постобработка интервью 

Приложение для полуавтоматической постобработки расшифровок интервью, полученных с помощью Whisper X. 
Помогает исследователям исправлять ошибки распознавания, чинить диаризацию и приводить текст к читаемому виду.

## Что делает приложение

1. **Загрузка**: принимает сырой `.txt` файл от Whisper X (формат `[SPEAKER_XX] текст`).
2. **Диаризация**: показывает реплики спикеров, позволяет назначить им роли (Соб. / Инф.) и предупреждает, если Whisper X не различил голоса.
3. **Склейка**: объединяет разорванные реплики и абзацы.
4. **LLM-проверка**: находит потенциальные ошибки в именах, топонимах и терминах с помощью локальной модели (Ollama / Qwen 2.5).
5. **Интерактивная правка**: выводит текст с подсветкой ошибок и предлагает варианты замены (из LLM, словарей или прошлых правок).
6. **Сохранение**: экспортирует готовый текст в `.docx`.

## Установка

1. Установите Python 3.10+.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
3. Установите Ollama.
4. Скачайте модель (в терминале):
    ollama pull qwen2.5:7b
5. Создайте модель с расширенным контекстом (для работы с длинными текстами).
    Создайте файл Modelfile с содержимым:
        FROM qwen2.5:7b
        PARAMETER num_ctx 32768
    И выполните:
        ollama create qwen2.5:7b-32k -f Modelfile

## Запуск

В папке проекта выполните:
    python gui.py

## Структура проекта

app/ — логика приложения (ядро)

    models.py — структуры данных

    pipeline.py — склейка реплик и назначение ролей

    llm.py — работа с LLM (два прохода: поиск ошибок и проверка)

    suggestions.py — сборка вариантов замены

    exporter.py — сохранение в .docx

resources/ — словари (имена, топонимы, термины, этнонимы)

data/ — папка для исходных файлов и перечня интервью

results/ — папка для готовых .docx и лога правок

gui.py — графический интерфейс (PySide6)

## Технологии

Python 3

PySide6 (GUI)

pymorphy3 (определение OOV-слов)

Ollama + Qwen 2.5 (локальная LLM для поиска ошибок)

python-docx (экспорт в Word)
